# Open incubated research project

Contributions, bounded agent trials and expert-agent review are open.
Read README.md, docs/CONTRIBUTING.md, docs/ROUND_RULES.md, and the current
assessment referenced by discover.json entry.brief. Read the applicable round
protocol before running a trial. Scientific
signoff is separate from permission to work. Preserve initial results and failed
attempts. Use a new research/<session>/ directory and record code/input hashes,
seed, budgets, all failures and human/agent provenance. Keep instance improvements,
new algorithms and real-world utility claims distinct. Do not weaken a verifier
to accept a candidate. Run tools/check.py and the candidate-specific checker.

The canonical repository is https://github.com/discoveryathome/water-networks.
Contributions and pull requests are open; acceptance and frontier changes require maintainer review.
Do not commit downloaded external input files. External outreach requires authorization. Dataset and dependency notices are in THIRD-PARTY.md; they are not
relicensed by the pilot's MIT license. Independent scientific review is pending.
